Este repositório reúne meus resumos, anotações, implementações e soluções dos exercícios do livro **Entendendo Algoritmos** (*Grokking Algorithms*), de **Aditya Y. Bhargava**.

O objetivo é consolidar o aprendizado dos principais algoritmos e estruturas apresentados no livro, registrando não apenas as soluções, mas também a intuição por trás de cada algoritmo, análises de complexidade e aplicações práticas.

> **Observação:** Este material foi produzido para fins de estudo e revisão. Os resumos representam minha interpretação do conteúdo do livro.

---

## 📖 Estrutura do repositório

Cada capítulo contém:

* 📚 Resumo dos conceitos
* 🧠 Explicação intuitiva dos algoritmos
* ⏱️ Análise de complexidade (Big-O)
* 💻 Implementações dos exemplos
* ✅ Resoluções dos exercícios
* 💡 Aplicações práticas
* 📌 Principais aprendizados
